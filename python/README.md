# mcp-schema-bridge

> Your MCP tools work on Claude but 400 on Gemini — or silently lose constraints under OpenAI strict mode.

`mcp-schema-bridge` rewrites MCP tool schemas per model API, tells you exactly what it changed, and maps the model's arguments back so they satisfy the original MCP server.

**Status:** pre-release, under active development. See [docs/PLAN.md](docs/PLAN.md).
